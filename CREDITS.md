# Credits

## Source

The original game and its source code (`diam38.zip`, `diam38/`, `src/`) came from hpcalc.org:

- https://www.hpcalc.org/details/529

Credit hpcalc.org and the authors on the published web page.

## Original authors

- **Douglas R. Cannon**: Diamonds for the HP48 (1993), ported to the HP 38G (1996-1997)
- **Detlef Mueller**: HP 38G aplet port and release (1997-1998)
- **Oliver Dreer**: the original Diamonds for the Macintosh, which the HP version is based on
- Paul Hart (SASM conversion), Jim Donnelly and Jean-Yves Avenard (HP 38G conversion help)

The game is freeware. From `DIAM38.TXT`: "You have the game, you have the source code.
You can play it, you can modify it, you can give it away, you can sell it."
